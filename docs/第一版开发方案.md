# dsh-plugin-litsearch：检索工作台（任务化 + 多检索式 + 筛选台账 + 独立设置页）

> 第一版开发方案 · 2026-11-10

## Context

当前插件只有「模型工具 + 一个简单侧栏面板」：模型检索后只得到一份 Markdown，用户在界面上无法看结果、改条件、预览或下载；面板检索不进历史、不与模型共享状态。

两份真实产出（《口臭文献检索与分层阅读清单》《口臭发病机制·机制分层清单》）暴露了真正的交付物形态：**不是一页搜索结果，而是一个可持续迭代的检索工作台**——11 条专题检索式合成一次任务、589 条去重记录、人工筛到 59 篇、与上一版任务对比出 46 篇新增、按机制分层、记录每篇"为什么读"与全文获取状态、最后导出可复现的 Markdown/CSV。本方案据此把插件从"搜索框"升级为"检索任务工作台"，并保持模型与面板操作同一份状态。

**可行性结论**：核心链路都有现成 API——`sidebarRightTabs.register({patterns, keepMounted, multiple})` 做每任务/每论文资源 tab，`ctx.sidebarRight.openResource(address, {params})` 程序化唤起（dsh-plugin-zotero 已在用），Host `webServer` 可自定义路由、读写文件、访问 `127.0.0.1:23119`；设置页可用 `settings.section` 席位 + `configForms` 表单模型注册。缺口只有 Host→Client 广播与工具结构化 UI 通道，用「Host 任务库 + 客户端轮询」补齐。

## 决策摘要

1. **单一执行路径**：检索永远由 Host 执行（限流、去重、排序、分页、缓存一份）。模型是「任务命令 + 文本投影」，面板是「任务状态投影 + 命令」。
2. **7 个文献源**：PubMed、Europe PMC、OpenAlex、Crossref、Semantic Scholar、arXiv、PubTator3。不做通用网页搜索与 ClinicalTrials/UniProt。
3. **Zotero 走本地 connector**（`127.0.0.1:23119/connector/*`），写入当前选中分类。
4. **模型检索自动打开任务 tab**，设置可关；无活动会话时降级为任务列表红点。
5. **任务即工作台**：多检索式、跨任务增量、筛读状态、分层分组、研究笔记、全文台账、可复现导出。
6. **概览统计是任务内的一等 tab**，与结果同级：几百篇结果先看分布与漏斗，再交叉筛选下钻。
7. **配置集中在 dsh 设置中心的独立一页**（`settings.section`），不再用插件行内的配置卡，避免双表单冲突。

## 从两份真实产出吸收的能力

| 产出里的做法 | 插件化设计 |
|---|---|
| 11 条专题检索式 → 一次合并检索 | 任务支持**检索式组**：多条具名 query，可分别启停、可给单源覆写语法，跨式去重并记录 `matchedQueries` |
| 589 条 → 人工筛出 59 篇 | **筛读台账**：未读/已读/纳入/排除四态，可加标签与备注，漏斗计数可见，CSV 保留全量 |
| 几百篇结果，用户无法快速形成全貌 | **概览统计页**（与结果同级 tab）：漏斗、年份/来源/期刊/作者/类型/语言分布、OA 与全文覆盖率、每条检索式的命中与"独有贡献"、高被引与最新 Top、筛读进度；统计块点击即筛到结果页 |
| "46 篇是上一版没有的" | **任务对比**：按稳定 `paperId` 与旧任务差分，标新增/已有；可继承旧任务筛读状态 |
| 按"底物层/酶层/群落层/宿主层"组织 | **任务内分组**（自由命名）+ 分组备注，列表可分组渲染，导出分层 Markdown 表 |
| 每篇一句"为什么读"、只读 8 篇 | 论文级 `note` + `shortlistOrder`，模型可批量写，面板显示"必读 N 篇 / 阅读路线" |
| 12 篇 PDF 到位、其余标注 cookie 墙/订阅制 | **全文台账**：每篇 `pdfStatus` 与失败原因，支持"缺全文"筛选与导出；Europe PMC `fullTextXML` 作为 HTML 全文兜底 |
| 复现检索式 + 检索日期 + 命中规模 | 任务保存原始检索式与执行时间、每式命中数，导出报告带可复现区块 |
| 中文文献单独一节 | `Paper.language` + 语言筛选；README 说明 PubMed 仅覆盖部分中文期刊，CNKI/万方不在范围 |
| 全量 CSV（DOI/PMCID/命中检索式/是否已读） | `/export?format=csv` 输出全量台账；另有 RIS/BibTeX/Markdown |

## 架构

```
literature_* 工具 ─┐
                   ├─ TaskService（唯一事实源 + 全局论文登记册）
面板 HTTP 路由 ────┘   ├─ runner：queries × providers → identity 去重 → RRF → 快照
                       └─ rev++ ─ GET /events 轮询 ─ client watcher ─ openResource

设置页（settings.section）── SettingsFormModel ── Host Config（volatile，热更新）
```

- 持久化 `~/.dsh/dsh-litsearch/`：`tasks/index.json`、`tasks/<id>.json[.gz]`、`papers/index.json`（跨任务首次出现/已读）、`pdfs/<sha256>.pdf`、`out/<taskId>/`（导出与 PDF 命名副本）。
- 写盘串行队列 + 临时文件 rename；状态变化立即 flush，普通变更 300ms 合并；dispose 时 flush。
- 裁剪：任务 120 条 / 90 天（pin 不过期）；单任务最多 **1500 条**（覆盖 589 这类批量检索），摘要存 800 字，gzip；论文登记册只存状态不存元数据。
- 事件用 1.5s 轮询（`document.hidden` 暂停、单飞）；长轮询/SSE 仅作后续增强。

## 数据模型（`src/search/types.ts` 扩展）

```ts
type TaskStatus = 'draft'|'queued'|'running'|'done'|'partial'|'error'|'canceled'
type TaskOrigin = 'model'|'panel'|'history'|'api'
type Screening = 'unread'|'read'|'included'|'excluded'
type PdfStatus = 'unknown'|'available'|'downloaded'|'paywalled'|'blocked'|'failed'

interface QueryBlock {
  id: string; name: string; text: string
  perSource?: Partial<Record<SourceId, string>>   // 单源语法覆写
  enabled: boolean
}

interface TaskConditions {
  queries: QueryBlock[]                            // 单检索式 = 长度 1
  sources: SourceId[]
  yearFrom?: number; yearTo?: number
  openAccessOnly: boolean; language?: 'any'|'eng'|'chi'
  types?: string[]; sort: 'relevance'|'citations'|'year'; pageSize: number
}

interface PaperState {
  screening: Screening; groupId?: string; shortlistOrder?: number
  note?: string; tags?: string[]; pdfStatus: PdfStatus; pdfError?: string
}

interface TaskGroup { id: string; name: string; description?: string; order: number }

interface SearchTask {
  id: string; title: string; conditions: TaskConditions; status: TaskStatus
  origin: TaskOrigin; sessionId?: string; fromTaskId?: string; rev: number
  createdAt: string; updatedAt: string; notes: string                 // 任务级研究笔记
  groups: TaskGroup[]
  cursor: { page: number; perSource: Partial<Record<SourceId, string|number>>; exhausted: boolean }
  progress?: { queryIndex: number; queryTotal: number; source?: SourceId }
  stats: { perQuery: Record<string, number>; rawHits: number; deduped: number
           screening: Record<Screening, number>; newVsBase?: number }
  result: { papers: Paper[]; totalLoaded: number; sources: SourceStatus[]; fetchedAt?: string }
  states: Record<string, PaperState>                                  // key = paperId
}

interface Paper {
  paperId: string; source: SourceId; sourceId: string
  ids: { doi: string; pmid: string; pmcid: string; arxivId: string; s2Id?: string; openalexId?: string }
  title: string; authors: string[]; year: number | null; venue: string
  doi: string; url: string; abstract: string; language?: string
  citedBy: number | null; openAccess: boolean; pdfUrl: string; type: string
  hitSources: { source: SourceId; rank: number }[]
  matchedQueries: string[]
  oaLocations: OaLocation[]
  annotations?: EntityAnnotation[]                                    // PubTator3，详情按需
}
```

## 设置页（dsh 设置中心）

**注册方式**（与 dsh-plugin-zotero 同法，已验证）：

```ts
const controller = new LitsearchSettingsController(ctx.configForms.get(ROW_ID))
ctx.effect(() => () => controller.dispose(), '...: settings form')
ctx.effect(
  () => ctx.configForms.whileServed([ROW_ID], () =>
    ctx.slots.inject('settings.section', () =>
      ctx.slots.register({
        name: 'settings.section',
        id: 'litsearch',
        order: 30,                         // 排在框架自带页之后
        label: () => t('settings.nav'),
        locale: NS,
        inject: () => controller.inject(),
      }, SettingsSection as ComponentType<never>))),
  '...: settings section',
)
```

- 用 `SettingsFormModel(scope, fields)` + `settingsTextField/settingsNumberField`；布尔/下拉/密钥/路径等自定义字段在插件内实现 `booleanField/selectField/secretField/pathField`（参考 ZoteroCard 的 `booleanField`）。
- **自动保存**（防抖 600ms），无保存按钮；非法草稿丢弃并保留上次有效值；`volatile` 保证改完即生效，无需重启。
- **移除** 现有 `ConfigCard` → `plugins.row.config` 的注册，只保留设置中心一页，避免两个 `SettingsFormModel` 绑同一 scope 互相覆盖。
- 页面结构（六个分组，可折叠）：
  1. **常规**：默认源、条数、排序、语言、自动打开任务 tab、任务 tab 上限。
  2. **数据源与密钥**：联系邮箱、NCBI key、S2 key、各源最小间隔、PubTator 标注开关；每项旁有状态徽标（已配置/未配置）。
  3. **全文与下载**：下载根目录（目录选择/校验可写）、命名模板（实时预览一个文件名）、大小上限、自动下载、Unpaywall 与 EPMC 兜底开关。
  4. **Zotero**：启用开关、connector 地址、附 PDF、标签前缀；「测试连接」显示版本与当前选中分类；提示需开启"允许其他应用通信"。
  5. **任务与存储**：存储目录（只读展示）、保留天数/条数、单任务上限、缓存上限；「清理旧任务」「清理 PDF 缓存」按钮（二次确认）。
  6. **诊断**：逐源「测试」按钮（发一条最小检索）、冷却状态、最近一次错误、版本与目录占用。
- 密钥字段：不回显原值，只显示「已配置」+「清除」；Host 不得把密钥写进 `/health` 或日志。
- 设置变更**不影响已有任务**；只影响新任务与新请求（下载目录、限流间隔等在下一次请求生效）。

**新增诊断端点**：

| 方法 | 路径 | 作用 |
|---|---|---|
| POST | `/settings/probe` | `{target:'pubmed'|'epmc'|'openalex'|'crossref'|'s2'|'arxiv'|'pubtator'|'unpaywall'|'zotero'|'pdfRoot'}` → 成功/失败原因 |
| POST | `/settings/cleanup` | `{scope:'tasks'|'pdf'|'all'}`，返回释放空间；二次确认由 UI 负责 |

## Host 路由（`src/host/router.ts`，前缀 `/dsh-litsearch/api`）

保留 `{ok,data}|{ok,error}` 信封、回环 Host 与 `sec-fetch-site` 栅栏；写端点另加 `x-dsh-litsearch-write: 1` + JSON content-type（参考 zotero 插件）。

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/health` | 各源可用/冷却、Zotero 探测、globalRev（不含密钥） |
| GET | `/tasks` | 历史列表（`q`、`origin`、`pinned`） |
| POST | `/tasks` | 新建；`queries[]`、`fromTaskId?`（继承筛读）、`runNow` |
| GET | `/tasks/:id` | 元信息、分组、笔记、漏斗统计、进度 |
| PATCH | `/tasks/:id` | 改条件/标题/笔记/分组；`expectedRev` 冲突 409 |
| DELETE | `/tasks/:id` | 删除 |
| POST | `/tasks/:id/run` | `mode:'new'|'more'`、`queryIds?`、202 + rev |
| POST | `/tasks/:id/cancel` | 取消进行中的检索 |
| GET | `/tasks/:id/results` | 分页 + 筛选：源、年份、OA、语言、类型、有 PDF、`screening`、`group`、`query`、`new=1`、排序 |
| GET | `/tasks/:id/stats` | 概览统计；接受与 `/results` 相同的筛选参数，`scope=task|filtered`；返回漏斗、分布、Top 榜、检索式贡献矩阵、覆盖率 |
| POST | `/tasks/:id/annotate` | 批量写 `states`（筛读/分组/必读/备注），≤50 条 |
| GET | `/tasks/:id/compare` | `with=<taskId>`：按 paperId 差分，返回新增/共有/缺失与计数 |
| GET | `/papers/:paperId` | 详情（含 oaLocations、PubTator 标注、全任务出现记录） |
| GET | `/papers/:paperId/pdf` | Host 代理 PDF（Range、`disposition=inline|attachment`） |
| GET | `/papers/:paperId/fulltext` | Europe PMC `fullTextXML` 转 HTML 阅读页（无 PDF 时兜底） |
| GET | `/zotero/probe` | connector ping + 当前选中分类 |
| POST | `/zotero/sync` | 批量同步（可选带 PDF） |
| GET | `/export` | `format=csv|ris|bibtex|md`，`taskId`、`ids?`、筛选参数 |
| GET | `/events` | `sinceRev` → `{rev, tasks:TaskSummary[]}`；rev 回退给 `reset` |
| POST | `/settings/probe` | 设置页诊断 |
| POST | `/settings/cleanup` | 清理任务/缓存 |

CSV 列固定：`paperId, title, authors, year, venue, doi, pmid, pmcid, arxivId, sources, matchedQueries, citedBy, openAccess, language, screening, group, shortlistOrder, pdfStatus, pdfError, note`。

### 统计口径（`/tasks/:id/stats`）

```ts
{
  rev, scope: 'task'|'filtered', loaded: number, totalHint?: number,
  funnel: { rawHits, deduped, filtered, included, excluded, unread, read },
  bySource: [{ id, hits, uniqueOnly, oa, withPdf }],
  byQuery:  [{ queryId, name, hits, uniqueOnly, overlap: Record<queryId, number> }],
  byYear:   [{ year, count, included }],
  byType / byLanguage: [{ key, count }],
  topVenues / topAuthors: [{ name, count }],          // 各取前 15
  metrics: { oaRate, pdfRate, htmlOnlyRate, medianCitations,
             topCited: paperId[], latest: paperId[], newVsBase? },
  screeningProgress: { included, excluded, pending },
  unavailableFullText: { paywalled, blocked, failed }
}
```

- **只统计已加载结果**，响应带 `loaded` 与 `totalHint`，UI 标注"基于已加载 N 篇（可继续加载）"。
- `uniqueOnly` 与 `overlap` 来自 `Paper.matchedQueries` 的位图统计（≤1500 篇 × ≤20 条检索式，毫秒级）。
- 服务端按 `rev + 筛选参数哈希` 做 30s 内存缓存；追加加载后 `rev` 变化自动失效。
- 模型侧 `literature_task action:'stats'` 返回同一口径的紧凑文本摘要（漏斗、年份区间、Top 期刊/作者、OA/全文覆盖率、每条检索式的独有贡献），供模型判断语料面貌后再做分层与缺口分析。

## 模型工具（`src/host/tools.ts`）

| 工具 | 参数 | 要点 |
|---|---|---|
| `literature_search` | `query` 或 `queries[]`(可带 name/perSource)、`sources`、`limit`、年份、OA、语言、类型、排序、`taskId?` | 建/复用任务并执行；返回任务头、每式命中数、前 10 条；长任务超 25s 返回 running + 进度 |
| `literature_task` | `action: list|get|update|run|annotate|compare|stats`、`id`、`patch`、`papers[]`、`withTaskId`、筛选、`limit` | 读条件/读全量紧凑列表/改条件/重跑/写筛读与笔记/对比旧任务/读语料统计 |
| `literature_sources` | — | 7 源能力、限流要求、冷却、检索式语法差异 |
| `literature_zotero` | `action: probe|sync`、`taskId`、`paperIds`、`withPdf` | 目标分类 + 每条结果 |

模型改条件写 `rev++` 并标 `changedBy:'model'`；面板草稿干净则重载，脏草稿显示横幅不覆盖。`literature_task get` 支持 `screening/group/query` 过滤，让模型能据筛读结果做机制分层与缺口分析，再 `annotate` 回写。

## 数据源（`src/search/providers/`）

`Provider.search` 返回 `ProviderPage{papers,nextCursor,total}`；每源独立限流队列（最小间隔 + 429/Retry-After 指数冷却），NCBI 单独串行队列。多检索式按「先 query 后 source」串行扇出，避免打爆限流，并上报 `progress`。

| 源 | 分页 | 限流 | 关键映射 |
|---|---|---|---|
| PubMed | esearch `retstart/retmax` → efetch XML | 无 key 3r/s，有 key 10r/s；`tool`+`email` | PMID、ArticleIdList→DOI/PMC、PubDate、摘要；支持 `[MeSH]`/`[tiab]`/`[dp]`/`[pt]`/`[Language]` 原样语法 |
| Europe PMC | `cursorMark` | 自限 5r/s | pmid/pmcid/doi、citedByCount、fullTextUrlList、`fullTextXML` |
| OpenAlex | `cursor` | polite pool `mailto` | inverted abstract、ids.pmid/pmcid、best_oa_location |
| Crossref | `cursor` | 自限 1r/s | 数组字段、JATS 摘要、link PDF |
| Semantic Scholar | `offset` | 无 key 100/5min + 3s gap；可选 key | externalIds、openAccessPdf、citationCount |
| arXiv | `start/max_results` | 1r/3s | Atom 解析、arxiv id、link rel=pdf |
| PubTator3 | `page/size` | 独立 350ms 队列 | `text_hl` 片段；实体标注详情按需 |

- **检索式适配**：`queries[].perSource` 优先；未给覆写时按源降级——PubMed 原样；EPMC 原样（支持同名布尔语法）；OpenAlex/Crossref/S2 去掉字段标签保留布尔词；arXiv 转 `all:`/`ti:`；PubTator 用纯文本。面板对"仅 PubMed 生效"的语法给出提示。
- **身份键**：doi > pmid > pmcid > arxivId > titleKey（NFKC、`\p{L}\p{N}`、<12 字符不参与、年份差 ≤1 兜底）。合并 `hitSources/ids/oaLocations/matchedQueries`，取最长摘要、最大被引、任一 OA。
- **RRF**：`Σ w_s/(60+rank_s)`，排序 score → 命中源数 → bestRank → 被引 → 年份；权重 PubMed 1.10、EPMC/OpenAlex 1.00、Crossref 0.95、S2 0.90、arXiv 0.85、PubTator 0.70。
- 年份/OA/语言下推能力不一致时（arXiv、PubTator）后置过滤，`SourceStatus.filtered=true`。

## 全文 / Zotero / 导出

- **PDF 解析链**（按需）：OpenAlex best_oa_location → EPMC fullTextUrlList → PMC → arXiv → S2 openAccessPdf → Unpaywall（需配置邮箱）。逐个尝试，HTML/非 PDF/403/超时/超 30MB 换下一个；**失败原因写入 `pdfStatus/pdfError`**。
- **下载**：Host fetch（仅 http/https、拒私网、≤5 重定向、20s、`%PDF-` 校验），缓存 `pdfs/<sha256>.pdf`，另存用户目录为可读名 `<第一作者><年份>_<短标题>_<PMID|DOI>.pdf`；每次任务导出落 `out/<taskId>/`。不接 Sci-Hub。
- **无 PDF 兜底**：EPMC `fullTextXML` 转 HTML 阅读页（论文 tab 内渲染），并在台账标 `available` 但 `pdfStatus=paywalled/blocked` 时提示"仅有 HTML 全文"。
- **Zotero**：`GET /connector/ping`、`POST /connector/getSelectedCollection`（显示目标分类）、`POST /connector/saveItems`（元数据 + DOI/PMID/arXiv 写入 extra + `dsh-litsearch` 标签）、`POST /connector/saveAttachment`（PDF 字节）。需开启"允许其他应用通信"并预先选中分类；只读/失败统一回退 RIS。
- **导出**：CSV 全量台账；RIS/BibTeX 供 Zotero/EndNote；**Markdown 报告**自动生成「检索日期 / 规模漏斗 / 检索式组（可复现）/ 分组表格（含"为什么读"）/ 必读阅读路线 / 全文获取情况 / 与对比任务差异 / 模型研究笔记」，对应两份样例的结构。

## 客户端 UI（`src/client/`）

- **页面 tab** `litsearch`：三段「新检索 / 任务 / 数据源」。新检索 = 检索式组编辑器（多条具名 query、可加单源覆写、启停）+ 7 源 Pill + 高级筛选（年份/OA/语言/类型/排序）。
- **资源 tab**：`dsh-resource://litsearch-task/**`、`dsh-resource://litsearch-paper/**`（`priority:'extension'`、`keepMounted:true`、`multiple:true`）。任务 tab = 工作台；论文 tab = 摘要/元数据/OA/实体/备注/筛读/下载/同步/插入。
- **自动打开**：watcher 轮询 `/events`；`origin==='model'` 的新任务且设置为开时 `openResource(taskAddress,{params:{title}})`；`seen:<taskId>:<rev>` 去重；同时最多 `maxTaskTabs` 个任务 tab；失败或 `sessionId` 不匹配写 `pendingOpen` + 红点。
- **任务 tab = 工作台**，顶部固定任务头（标题、条件摘要、`第 i/N 条检索式` 进度、漏斗、运行/改条件/导出），正文为**同级 tab**：`概览 · 结果 · 分组 · 台账 · 笔记`。
- **概览（统计）tab**——解决"几百篇看不出全貌"：
  - 语料漏斗：每式/每源命中 → 跨式去重 → 当前筛选 → 纳入/排除；
  - 年份分布柱（总量与纳入叠加）、来源构成（命中/独有贡献/OA/有全文）；
  - 期刊 Top 15、作者 Top 15、文献类型、语言；被引 Top 10、最新 10 篇；
  - 全文覆盖：OA 可下载 / 仅 HTML / 订阅制 / 被墙 / 未尝试；筛读进度与对比任务的新增数；
  - 检索式贡献表：每条命中数、独有命中数、两两重叠计数（点击切到"仅该式独有"）；
  - **所有统计块可点击**，跳到结果 tab 并带上对应筛选；顶部提供 `全部任务 / 当前筛选` 口径切换；图表用 CSS 柱 + 内联 SVG，不引入图表库。
- **结果 tab**：筛选栏（源/年份/OA/语言/筛读态/分组/仅有全文/关键词）；结果按 RRF 或分组渲染；卡片含命中源 chips、命中检索式（折叠）、模型备注；行操作 `预览/原文/下载/Zotero/插入`；批量条：标记已读/纳入/排除、分组、写备注、导出、同步、下载（≤50）。
- **分组 tab**：分组管理（新建/改名/排序）+ 分组内排序；`shortlistOrder` 形成"必读 N 篇"阅读路线。
- **台账 tab**：全文获取情况（成功/订阅/被墙/失败原因）与"缺全文"清单，可直接导出 CSV；**笔记 tab**：任务级研究笔记，用户可编辑、模型可写。
- **对比视图**：选旧任务 → 新增/共有/缺失三栏，默认只看新增，可整批"纳入候选"。
- **窄面板**：标题 13px 两行截断；元数据 11px 单行 + `title`；标签最多 2 个余下收进 Menu；操作 ≤4 字 + Tooltip；点击目标 ≥28px。
- **插入对话**：复用 `insertBuilt`；批量一次捕获、编号输出，可按当前筛选或分组插入。

## 风险与规避

| 风险 | 规避 |
|---|---|
| `openResource` 无活动会话时不唤起 | try/catch + `pendingOpen` + 红点 + 设置可关；实现时实测 |
| 多检索式打爆限流 | 先 query 后 source 串行 + 每源队列/冷却 + 进度上报 + 可取消 |
| 单源语法差异导致 0 命中 | `perSource` 覆写 + 降级适配 + 面板提示 + 单源 0 命中显式展示 |
| 出版商 403/CORS/HTML 墙 | 多候选逐个试 + Host 代理 + 内容校验 + 台账记录原因 + EPMC HTML 兜底 |
| Zotero 关闭/只读/重复导入 | probe 显示目标分类；`filesEditable` 检查；回退 RIS；文档说明重复风险 |
| 快照体积 | 1500 条上限、摘要 800 字、gzip、120 条/90 天裁剪 |
| 统计与列表口径不一致 | 统计与列表共用同一筛选解析与同一份已加载数据；`/stats` 返回 `loaded`；单测对比 `deduped` 与列表 `totalLoaded` |
| 统计计算成本 | 仅对 ≤1500 条内存聚合；按 `rev+筛选哈希` 缓存 30s；重叠矩阵按检索式位图统计 |
| 轮询开销 | 1.5s 轮询 + 隐藏暂停 + 单飞 + 只传摘要 |
| dsh 客户端 API 漂移 | 最小结构接口 + 特性检测；不改 engines |
| PDF 代理 SSRF | 仅 http/https、拒私网、限重定向/大小/超时、`%PDF-` 校验 |
| 设置页席位在旧宿主未声明 | 先 `whileServed` 再 `slots.inject`；未声明时不注册；保留 ConfigCard 源码作为回退，必要时在插件页重新挂载 |
| 双设置表单互相覆盖 | 只注册 `settings.section`，移除 `plugins.row.config` 的 ConfigCard |
| 密钥明文落盘 | 不写日志、不返回给客户端；UI 只显示"已配置"；文档提示配置文件为明文，建议本机使用 |
