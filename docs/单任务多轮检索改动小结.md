# 单任务多轮检索改动小结（2026-11-10）

给测试用的一句话：**一个研究主题 = 一个搜索任务 = 一个右侧栏 tab；同一任务里可以反复调整条件重搜，每轮留下历史记录。**

## 怎么生效

源码、`client/client.js`、`lib/` 构建产物都已生成，**重载插件即可**，无需重新构建。
本机没有 pnpm，验证用的是 `node_modules/.bin/tsc`、`tsdown`、`node --test`。

> 界面是注入 DSH 宿主的客户端模块，不是独立网页。请在宿主里加载插件后看右侧栏「文献检索」，
> **不要**把 `client/client.js` 当静态页面直接打开（那样缺少宿主上下文，跑不起来）。

## 改了什么

| 需求 | 实现 |
| --- | --- |
| 模型可自建并命名任务、可复用已有任务 | `literature_search` 新增 `title` / `taskId` / `newTask`。Host 记住「当前任务」（15 分钟 TTL），不指定参数即复用、开新一轮；换主题才 `newTask: true` + `title` 新建。任务 id 与 tab 都不变 |
| 轮次历史时间轴 | 新增 `SearchRound`：每轮记时间、条件深拷贝快照、发起方、命中/去重/加载数、状态、跳过/失败源数，**不存文献列表**，每任务保留最近 30 轮。任务页右上角「查看检索历史」图标 → 弹窗竖线时间轴 → 「回填条件重跑」 |
| 只给建议、不自动下一轮 | 工具 description + 每轮返回尾句写死约束，并覆盖 `literature_task run` 旁路；上一轮还在跑时先等 12s，仍忙就返回提示，**绝不新建任务** |
| 任务列表可删除/重命名 | 主页 + 任务页 header 右上角「搜索任务列表」图标 → 弹窗列出全部任务，可打开、重命名、二次确认删除；改名同步 tab 标题，删除清理本地缓存，跨 tab 自动刷新 |

附带修掉 `autoOpen.ts` 的累计计数 bug（`opened.length` 只增不减导致累计超 5 后不再自动开 tab），并加了「2 分钟内最多自动开 1 个 tab」的保险丝。

新增端点：`GET /tasks/:id/rounds`、`POST /tasks/:id/activate`；`literature_task` 增加 `rounds` action。

## 自测清单

- [ ] **单任务单 tab**：让模型连续两次检索同一主题（例如「口臭的治疗方案相关文献」，再说「换几个角度补充一下」）→ 只出现 **1 个任务 tab**，任务名由模型给，第二次落进同一任务，任务 id 不变。
- [ ] **换主题新建**：明确说一个不相干的新主题 → 模型应传 `newTask: true` 并给新任务名，此时才出现第 2 个 tab。
- [ ] **轮次时间轴**：任务页右上角历史图标 → 时间轴应显示 2 轮，每轮有「第 N 轮」、发起方、检索条件与篇数；旧一轮的条件不被后一轮污染。
- [ ] **回填条件重跑**：点某一轮的「回填条件重跑」→ 在同一 tab 里新增 1 轮，任务 id 不变；已标过的「已读/纳入/排除/备注」按文献身份保留。
- [ ] **不自动下一轮**：每轮结束后模型只输出「如何完善检索」的建议，不自行再搜一次；在面板改条件或在对话里明确要求后才进入下一轮。
- [ ] **任务列表**：主页和任务页右上角都能打开列表 → 可打开任务、重命名（tab 标题同步）、二次确认删除；在另一个 tab 里做的改动，列表会自动刷新。
- [ ] **上限与并发**：连续重跑超过 30 轮只保留最近 30 条；上一轮还在跑时再发起，应返回「上一轮仍在检索中」而不是新建任务。
- [ ] **回归**：上一轮的限流修复仍生效（冷却期排队等待、429 退避重试、限流跳过不出红字、Europe PMC 20s/25s 超时）。

## 已知限制

1. 工具执行上下文拿不到 session id，「当前任务」是进程内最近任务 + TTL，多会话共享进程时可能误并主题；模型可用 `newTask` / `taskId` 纠正。
2. 宿主 `sidebarRight` 没有关闭 tab 的能力，被删任务已打开的 tab 会显示「任务不存在」，需手动关。
3. 面板新建任务**不**自动设为当前任务；面板 rerun 会设。首轮新建是隐式的，没有「只建空任务」的动作。
4. 未处理的历史项：摘要里的 `<h4>` 标签、每源条数静默 ×2（都不属于本轮范围）。
